# ATS_SCORER
AI Resume ATS System --> this is basically filter our resume on the basis of their score plus domain of their specific role / job description and many more thing it answer where we need to work , where we are lacking and how much we align/match to that specific role we apply.

## Streamlit frontend

The frontend dependencies are listed in `frontend/requirements.txt`. To deploy on
Streamlit Community Cloud, set the app's main file to
`frontend/streamlit_app.py`; Cloud will install the requirements from the same
directory.
